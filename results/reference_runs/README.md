# Selected Reference Runs

This folder stores stable aliases for the two selected models:

- `4K` (geometry-first winner): `outputs/reference_models/4K`
- `7K` (primary-7 weighted winner): `outputs/reference_models/7K`

Alias mapping is recorded in `results/reference_runs/selected_runs_4k_7k.json`.

Use these aliases in downstream sampler sweeps and final assessments to avoid long, error-prone paths.
